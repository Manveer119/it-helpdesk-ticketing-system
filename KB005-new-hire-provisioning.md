# KB005 — New Hire Account & Asset Provisioning Checklist

**Category:** Account / Active Directory, Asset Request
**Priority:** Medium (has a hard deadline: the employee's start date)
**Last updated:** July 2026

## Purpose
Standardize the steps for setting up a new employee so nothing is
missed before their first day, and so provisioning tickets are handled
consistently regardless of which technician picks them up.

## Checklist

### Account Setup (complete at least 1 business day before start date)
- [ ] Create Active Directory account in the correct OU for the
      employee's department
- [ ] Add account to required security groups (department shared
      drives, distribution lists)
- [ ] Provision Microsoft 365 mailbox and license
- [ ] Set a temporary password with **must change at next logon**
      enabled
- [ ] Confirm manager/department for correct group assignments before
      provisioning — don't guess

### Hardware / Asset Setup
- [ ] Pull a laptop or desktop from inventory (or order if none
      available — flag lead time to the requesting manager)
- [ ] Image the device with the standard department build
- [ ] Log the asset: serial number, asset tag, assigned user,
      department, and date issued in the asset inventory
- [ ] Set up docking station, monitor(s), and peripherals if the role
      requires them
- [ ] Confirm device joins the domain successfully and the new
      account can log in

### Day-One Readiness
- [ ] Confirm email is receiving/sending correctly
- [ ] Confirm access to required shared drives/folders
- [ ] Provide the user with a quick-reference sheet: password policy,
      how to submit a help desk ticket, IT contact info
- [ ] Close out the provisioning ticket only after confirming the user
      has successfully logged in and can access what they need

## Notes
This checklist reduces first-day support tickets significantly by
catching most account/access issues before the employee's first
login attempt rather than reacting to them.
